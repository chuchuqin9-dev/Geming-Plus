# MOBA 对战模拟器 / MOBA 数值实验室

> 基于「时间轴 + 战斗事件」驱动的 MOBA 数值模拟分析平台。
>
> 用于英雄属性分析、装备搭配测试、木桩 DPS、英雄 1V1、方案对比与战斗时间轴回放。

---

## 项目介绍

这是一款面向玩家的 **MOBA 数值实验工具**，不是动画演示工具。核心目标是：

> **谁输出更高？谁更耐打？哪套装备收益最高？不同时间段强弱如何变化？**

通过**事件驱动模拟（Event Driven Simulation）**复现普通攻击、技能释放、装备触发、暴击、吸血、护盾、穿透、减伤、持续伤害等机制，精确还原战斗过程并生成可回放的时间轴。

**优先级（长期不变）：**

```
计算准确 > 规则清晰 > 结果可复现 > 架构可扩展 > 操作方便 > 界面美观 > 动画效果
```

## 战斗规则

- 事件驱动模拟，内部统一使用**毫秒**作为时间单位，避免浮点累计误差。
- 同时间多事件按**确定性优先级**处理（状态更新→技能释放→普攻→伤害→暴击→装备触发→护盾→减伤→扣血→吸血→死亡）。
- 模拟支持**随机模式**与**期望模式**；随机模式使用 Random Seed，相同配置 + Seed 可 **100% 复现**结果。

### 伤害结算顺序

```
1 计算原始伤害
2 技能/普攻增伤
3 暴击
4 抗性穿透
5 抗性减伤
6 额外修正
7 伤害减免
8 护盾吸收
9 扣除生命值
10 吸血/回复
11 装备/被动触发
12 死亡判定
```

## 公式说明

### 护甲减伤

```
减伤率 = 护甲×0.06 / (1 + 护甲×0.06)
实际物理伤害 = 原始伤害 × (1 - 减伤率)
```

### 护甲穿透（面板护甲 > 18）

```
最终护甲 = (面板护甲 - 18)×(1 - 百分比穿透) + 18 - 固定穿透
（<= 18 时：最终护甲 = 面板护甲 - 固定穿透；最终护甲 = max(0, …)）
```

### 魔抗减伤与法术穿透（规则同护甲，阈值 12）

```
减伤率 = 魔抗×0.06 / (1 + 魔抗×0.06)
最终魔抗（>12）= (魔抗-12)×(1 - 百分比穿透) + 12 - 固定穿透
最终魔抗 = max(0, …)
```

### 冷却

```
实际冷却 = 基础冷却 × (1 - 冷却缩减)
```

### 吸血 / 护盾 / 治疗 / 溢出

- 物理吸血按实际物理伤害、法术吸血按实际魔法伤害、全能吸血跨类型。
- 治疗不超过最大生命值；记录实际治疗与溢出治疗。
- 真实伤害默认无视抗性；是否受「伤害减免」影响由系统配置决定。

## 数据结构说明

核心类型见 [src/core/types.ts](./src/core/types.ts)：`Hero / HeroStats / Equipment / EquipmentEffect / Skill / DamageEffect / Trigger / Combatant / CombatConfig / CombatEvent / CombatResult / SimulationPreset` 等。所有用户数据均带 `schemaVersion`，支持版本迁移。

数据流：

```
用户配置 → 标准化 CombatConfig → 事件队列 → 伤害/效果计算 → CombatResult → 统计 → 图表/时间轴
```

## 数据备份（无云端方案）

采用「分层降级」策略：

1. **主存储**：IndexedDB（Dexie）——容量大，适合大量模板。
2. **跨设备**：`导出 JSON / 导入 JSON`（单文件 `moba-simulator-backup.json`）+ 剪贴板复制粘贴模板。
3. **轻量分享**：小型模板（单个英雄/装备）二维码编码。
4. **仓储接口**：`StorageAdapter` 解耦本地实现；将来提供 `RemoteAdapter`（Supabase 等）即接云端，业务代码零改动。
