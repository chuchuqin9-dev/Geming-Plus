# MOBA 对战模拟器（MOBA 数值实验室）

一个可以**在本地运行**的英雄搭配与战斗数值模拟工具。用它来回答这类问题：

> 谁输出更高？谁更耐打？哪套出装收益最大？强弱在不同时间点如何变化？

它会在浏览器里模拟普通攻击、技能释放、暴击、护甲/魔抗减伤、吸血、护盾、持续伤害等机制，并生成可回放的战斗时间轴，全部数据（英雄、装备、技能、历史记录）都保存在**你自己电脑的浏览器本地**，无需联网。

---

## 一、环境要求（唯一）

| 项目 | 要求 |
| --- | --- |
| 电脑系统 | Windows 10/11（或 macOS、Linux） |
| 需要安装的软件 | **Node.js**（LTS 稳定版即可，自带 npm） |
| 必装工具 | Node.js 官网：<https://nodejs.org/> |
| 网络 | 首次启动安装依赖时需要联网；之后使用**无需联网** |

> 不需要数据库、不需要 Docker、不需要后端服务器。本项目是纯前端网页应用。

---

## 二、安装步骤

1. 下载并安装 **Node.js LTS 版**（<https://nodejs.org/>），一路「下一步」即可。
2. 解压本项目文件夹到任意位置（例如 `D:\MOBA模拟器`）。
3. **不要删除** 文件夹里的文件和 `package.json`（依赖清单 / 锁定文件）。

> 第一次启动时脚本会自动安装项目依赖（`node_modules`），并可能耗时几分钟。

---

## 三、启动方式（推荐：双击一键启动）

### Windows

双击项目根目录下的 **`启动模拟器.bat`**

执行后会自动：
1. 检查 Node.js 是否安装；
2. 若无依赖则自动安装；
3. 启动本地网页服务；
4. 自动打开浏览器访问。

### macOS / Linux

双击 **`启动模拟器.sh`**（若首次无法双击，先在终端执行一次 `chmod +x 启动模拟器.sh`）。

### 默认访问地址

```
http://localhost:5173/
```

> 若 5173 端口被占用，程序会自动换一个端口，并以黑色窗口里显示的地址为准。

## 四、停止与再次启动

- **停止**：关闭启动时弹出的黑色命令窗口。
- **再次使用**：再次双击启动文件即可。
- **数据保留**：关闭后英雄/装备/技能/历史记录都还在（存在你的浏览器本地）。

## 五、日常使用流程

1. 启动后在浏览器打开页面；
2. 到「英雄库」新建或选择英雄；
3. 到「技能库 / 装备库 / 天赋库」配置你的英雄；
4. 到「战斗模拟」选择英雄与木桩（或 1V1 对手）→ 点击「开始模拟」；
5. 查看 DPS、伤害构成、战斗时间轴；用「方案对比」比较多套出装。

## 六、常见问题（FAQ）

**Q1：双击后弹出「未检测到 Node.js 运行环境」？**
说明还没装 Node.js。请到 <https://nodejs.org/> 下载 LTS 版并安装（装完需重启或重新打开终端），再双击启动文件。

**Q2：提示「dependency 安装失败 / npm 报错」？**
一般是网络问题。请确认能上网，稍后重新双击启动文件重试。

**Q3：浏览器打开后是空白页 / 打不开地址？**
请确认黑色服务窗口里的地址，端口可能不是 5173。把黑色窗口里显示的 `http://localhost:xxxx/` 复制到浏览器访问。

**Q4：端口被占用怎么办？**
关掉占用该端口的其他程序，再重新双击启动。脚本会自动遍历 5173–5180 寻找空闲端口。

**Q5：之前建的英雄/数据没了？**
数据存在浏览器本地（IndexedDB）。如果换浏览器或者清除浏览器数据会丢失。建议在「设置」里**导出 JSON 备份**，换环境后「导入」恢复。

**Q6：我想在别处（部署到服务器/静态托管）运行？**
本项目是纯静态站点，执行 `npm run build` 后把 `dist/` 目录发布到任意静态托管（GitHub Pages / Nginx 等）即可。之后用 `npm start` 本地预览构建产物。

## 七、命令行方式（可选，开发用途）

若你熟悉命令行，也可以：

## 十、伤害结算顺序（规则）

```
原始伤害 → 增伤 → 暴击 → 抗性穿透 → 护甲/魔抗减伤
→ 额外修正 → 伤害减免 → 护盾吸收 → 扣生命 → 吸血/回复 → 效果触发 → 死亡判定
```

护甲减伤公式：`减伤率 = 护甲×0.06 / (1 + 护甲×0.06)`；魔抗规则相同。原始/真实伤害无视抗性。
